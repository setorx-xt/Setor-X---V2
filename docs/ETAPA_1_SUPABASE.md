# ETAPA 1 — Supabase

1. Crie o projeto no Supabase.
2. Vá em SQL Editor.
3. Rode `supabase/schema.sql`.
4. Em Authentication > Providers, ative Email/Password.
5. Copie Project URL e anon/public key.
6. Cole em `assets/js/online-config.js`.
7. Crie sua conta no app.
8. Rode `supabase/promover-mentor.sql` trocando pelo seu e-mail.

A camada online adiciona login, liberação de alunos, planejamento individual, Banco QX coletivo e ranking, sem remover o Setor X local.
